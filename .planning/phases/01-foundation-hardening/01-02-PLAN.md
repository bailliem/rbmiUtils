<objective>
Refactor analyse_mi_data() to use inherits() for method type detection instead of fragile class()[[2]] positional indexing, migrate error messages to cli::cli_abort(), and add lifecycle deprecation warnings on internal helpers (HRD-02).

Purpose: The current `class(method)[[2]]` pattern breaks if rbmi changes its class hierarchy. `inherits()` is the R-standard way to check class membership and is robust against class vector reordering. Internal helpers (`as_analysis2`, `extract_covariates2`, `as_simple_formula2`) are copies of rbmi internals that accumulate drift -- marking them as deprecated with a clear migration path reduces maintenance burden.

Output: Refactored analyse_mi_data.R with inherits()-based method detection, cli-formatted errors, lifecycle deprecation on internal helpers, and updated tests.
</objective>

   - No valid IMPID -> `cli::cli_abort("{.arg data} has no valid IMPID values.", class = "rbmiUtils_error_validation")`
