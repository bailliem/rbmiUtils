2. In R/tidiers.R, replace the current `tidyr::separate()` call with `tidyr::separate_wider_regex()` using named capture groups. The current code (lines 98-106) uses `sep = "_"` which breaks on parameter names containing underscores.

The parameter formats to handle are:
- ANCOVA treatment: `"trt_Week 24"` -> parameter_type="trt", lsm_type=NA, visit="Week 24"
- ANCOVA LSM ref: `"lsm_ref_Week 24"` -> parameter_type="lsm", lsm_type="ref", visit="Week 24"
- ANCOVA LSM alt: `"lsm_alt_Week 24"` -> parameter_type="lsm", lsm_type="alt", visit="Week 24"
- Gcomp treatment: `"trt_Drug A vs Placebo_Week 24"` -> parameter_type="trt", lsm_type=NA, visit="Week 24"
- Gcomp LSM: `"lsm_Placebo_Week 24"` -> parameter_type="lsm", lsm_type="Placebo", visit="Week 24"

Strategy: Use two-pass parsing:
- First regex: capture `parameter_type` as the prefix before the first `_`, and `remainder` as everything after.
- Then split `remainder` context-dependently: for "lsm" types, the second token (ref/alt/arm name) is `lsm_type` and the rest is `visit`; for "trt" types, the entire remainder is `visit` (unless it contains " vs " which indicates a gcomp comparison -- in that case, extract the visit after the last `_` that follows the comparison pattern).

A robust approach: use `tidyr::separate_wider_regex()` with the pattern:
```r
df |> tidyr::separate_wider_regex(
  parameter,
  patterns = c(
    parameter_type = "^(trt|lsm)",
    "_",
    remainder = ".*"
  ),
  too_few = "align_start",
  cols_remove = FALSE
)
```
Then parse `remainder` conditionally based on `parameter_type`:
- If `parameter_type == "lsm"`: split remainder on first `_` -> lsm_type and visit
- If `parameter_type == "trt"`: remainder is the visit (for ANCOVA) or contains "vs" comparison info (for gcomp -- extract visit as the part after the last `_` that follows arm names)

IMPORTANT: The superseded `tidyr::separate()` function must be replaced. Do NOT use `sep = "_"`. Use `tidyr::separate_wider_regex()` which is the modern replacement.

test_that("tidy_pool_obj handles parameter names with underscores", {
  # Create a minimal mock pool object with underscore-containing visit names
  # The pool object is a data.frame with class "pool" containing columns:
  # parameter, est, se, lci, uci, pval
  mock_pool <- data.frame(
    parameter = c("trt_Week_24", "lsm_ref_Week_24", "lsm_alt_Week_24",
                  "trt_Follow_Up", "lsm_ref_Follow_Up", "lsm_alt_Follow_Up"),
    est = c(-2.5, 10.1, 7.6, -1.8, 9.5, 7.7),
    se = c(0.8, 0.5, 0.6, 0.9, 0.5, 0.6),
    lci = c(-4.1, 9.1, 6.4, -3.6, 8.5, 6.5),
    uci = c(-0.9, 11.1, 8.8, -0.0, 10.5, 8.9),
    pval = c(0.002, NA, NA, 0.05, NA, NA),
    stringsAsFactors = FALSE
  )
  class(mock_pool) <- c("pool", "data.frame")

  result <- tidy_pool_obj(mock_pool)

  # Verify underscore-containing visits are preserved intact
  expect_true("Week_24" %in% result$visit)
  expect_true("Follow_Up" %in% result$visit)

  # Verify parameter_type is correctly identified
  expect_equal(sum(result$parameter_type == "trt"), 2)
  expect_equal(sum(result$parameter_type == "lsm"), 4)

  # Verify lsm_type is correctly identified
  lsm_rows <- result[result$parameter_type == "lsm", ]
  expect_true(all(lsm_rows$lsm_type %in% c("ref", "alt")))

  # Verify trt rows have NA lsm_type
  trt_rows <- result[result$parameter_type == "trt", ]
  expect_true(all(is.na(trt_rows$lsm_type)))
})
