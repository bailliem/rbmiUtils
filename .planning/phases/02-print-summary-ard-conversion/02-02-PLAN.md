Replace the existing print.analysis() and summary.analysis() methods in R/analyse_mi_data.R with cli-formatted versions. Keep the same roxygen2 documentation structure but update the function bodies.

**print.analysis(x, ...)**:
Replace all cat() calls with cli equivalents:
- cli::cli_h1("Analysis Object") instead of cat("Analysis object from rbmiUtils\n")
- cli::cli_text("{length(x$results)} imputation{?s} analysed with {.fn {x$fun_name}}") for the core info line
- cli::cli_rule() as separator
- Use cli::cli_text("{.field Method}: {method_class}") for method type
- Use cli::cli_text("{.field Pooling}: {result_class}") for pooling class
- Use cli::cli_text("{.field Delta}: {delta_text}") where delta_text is "Applied" or "None"
- Add NEW features per PRT-03:
  - Extract parameter names from x$results[[1]] (if available and is a list)
  - Show parameter count: cli::cli_text("{.field Parameters}: {n_params}")
  - Extract visit names from parameter names (remove "trt_", "lsm_ref_", "lsm_alt_" prefixes, get unique visit portions)
  - Show visits covered: cli::cli_text("{.field Visits}: {paste(visits, collapse = ', ')}")
- End with cli::cli_text("") and cli::cli_text("Next: {.code pool_obj <- rbmi::pool(analysis_obj)}")
- Return invisible(x)

**summary.analysis(object, n_preview = 5, ...)**:
Replace all cat() calls with cli equivalents:
- cli::cli_h1("Analysis Object Summary") as header
- cli::cli_h2("Imputations") section with count
- cli::cli_h2("Analysis") section with function name, delta status
- cli::cli_h2("Method") section with type and samples
- cli::cli_h2("Pooling") section with method and parameter count
- Add NEW feature per PRT-04: Parameter Preview Table
  - If x$results[[1]] is a named list, extract first n_preview parameter names
  - Show cli::cli_h2("Parameter Preview (from first imputation)")
  - For each parameter, show: cli::cli_text("  {p}: est={round(est, 3)}, se={round(se, 3)}")
  - If more parameters exist: cli::cli_text("  ... and {remaining} more")
- End with cli::cli_text("") and next steps using cli::cli_text()
- Return invisible(summary_info) as before

**Keep the inherits()-based method detection logic exactly as-is** -- that was hardened in Plan 01-02. Only change the output formatting from cat() to cli.
