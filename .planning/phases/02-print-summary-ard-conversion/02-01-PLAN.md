<task type="auto">
  <name>Task 1: Create print.pool and summary.pool S3 methods</name>
  <files>R/pool_methods.R</files>
  <action>
Create a new file R/pool_methods.R containing two exported S3 methods:

**print.pool(x, digits = 2, ...)**:
- Call tidy_pool_obj(x) to get the tidy tibble
- Use cli::cli_h1("Pool Object") as header
- Show metadata: number of parameters, number of unique visits, method (from x$method), N imputations (from x$N), confidence level (from x$conf.level)
- Use cli::cli_rule() as separator
- Display a formatted results table using print() on a rounded data frame (round est, se, lci, uci to `digits`; format pval using format_pvalue())
- Show only the key columns: parameter, visit, est, lci, uci, pval (drop parameter_type, lsm_type, se, description for compact display)
- Return invisible(x) -- NOT the tidy_df

**summary.pool(object, alpha = 0.05, ...)**:
- Call tidy_pool_obj(object) to get the tidy tibble
- Use cli::cli_h1("Pool Object Summary") as header
- Show metadata section: method, N imputations, confidence level, alternative
- Show a visit-level breakdown: loop over unique visits, print cli::cli_h2(visit_name)
- Within each visit, show treatment comparison rows with significance flag: mark with "*" if pval < alpha, "**" if pval < 0.01, "***" if pval < 0.001
- Also show LSM rows under each visit
- Return invisible(list(n_parameters, visits, method, n_imputations, conf.level, tidy_df)) for programmatic access

**Roxygen2 notes:**
- Use @export on both methods so roxygen2 generates S3method(print,pool) and S3method(summary,pool) in NAMESPACE
- Document the expected "Registered S3 method overwritten by 'rbmiUtils': method print.pool from rbmi" warning -- this is acceptable (same pattern as print.analysis)
- Use @param, @return, @seealso (link to tidy_pool_obj, rbmi::pool)
- Include @examples with \donttest{} wrapping

**Do NOT use cat() directly.** Use cli::cli_text(), cli::cli_h1(), cli::cli_h2(), cli::cli_rule(), cli::cli_bullets() for all output. This is consistent with Phase 1 patterns.

**Do NOT return the tidy data frame from print.** print.pool MUST return invisible(x).
