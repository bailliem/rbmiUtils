  <name>describe_imputation() with missingness breakdown</name>

  <behavior>
    describe_imputation(impute_obj) extracts metadata from an rbmi imputation object:

    **Fields:**
    - method: Human-readable method name (same mapping as describe_draws: "Bayesian (MCMC via Stan)", "Approximate Bayesian", "Conditional Mean (jackknife)", "Conditional Mean (bootstrap)")
    - method_class: Raw class name ("bayes", "approxbayes", "condmean")
    - n_imputations: Number of imputations (M) = length(impute_obj$imputations)
    - references: The reference arm mapping (named character vector from impute_obj$references)
    - n_subjects: Total number of unique subjects
    - visits: Character vector of visit names
    - missingness: data.frame with columns (visit, group, n_total, n_miss, pct_miss)
      - Built by cross-tabulating impute_obj$data$is_missing by visit and group
      - pct_miss = round(100 * n_miss / n_total, 1)

    **Return:** S3 class c("describe_imputation", "list")

    **print.describe_imputation(x, ...):**
    - cli::cli_h1("Imputation Summary")
    - Method, M, subjects
    - cli::cli_rule()
    - cli::cli_h2("References") -- show each arm mapping as "{arm} -> {reference}"
    - cli::cli_h2("Missingness by Visit and Arm") -- format as aligned table
    - Returns invisible(x)

    **Input validation:**
    - If impute_obj does not inherit "imputation", call cli::cli_abort() with class c("rbmiUtils_error_type", "rbmiUtils_error")

    **Extracting missingness from longdata R6 object:**
    The impute_obj$data is a longdata R6 object with these fields:
    - $visits: character vector of visit names
    - $ids: character vector of subject IDs
    - $is_missing: named list (by subject) of logical vectors (by visit)
    - $group: named list (by subject) of group labels

    Extraction pattern:
    ```r
    visits <- impute_obj$data$visits
    ids <- impute_obj$data$ids
    groups_list <- impute_obj$data$group
    is_missing_list <- impute_obj$data$is_missing

    # Build group vector
    grp_vec <- vapply(ids, function(id) as.character(groups_list[[id]]), character(1))

    # Build missingness matrix
    miss_mat <- matrix(
      unlist(is_missing_list[ids]),
      ncol = length(visits),
      byrow = TRUE
    )
    colnames(miss_mat) <- visits
    rownames(miss_mat) <- ids

    # Aggregate by visit x group
    unique_groups <- unique(grp_vec)
    missingness <- expand.grid(visit = visits, group = unique_groups, stringsAsFactors = FALSE)
    missingness$n_total <- NA_integer_
    missingness$n_miss <- NA_integer_
    for (i in seq_len(nrow(missingness))) {
      subjs <- names(grp_vec[grp_vec == missingness$group[i]])
      missingness$n_total[i] <- length(subjs)
      missingness$n_miss[i] <- sum(miss_mat[subjs, missingness$visit[i]])
    }
    missingness$pct_miss <- round(100 * missingness$n_miss / missingness$n_total, 1)
    ```

    **Edge cases:**
    - No missing data: all n_miss = 0, pct_miss = 0.0
    - Single visit: one row per group
    - Single group: one row per visit
    - references is NULL (J2R default or not specified): handle gracefully, show "No explicit references" in print
