<feature>
  <name>describe_draws() with MCMC diagnostics</name>
  <files>R/describe.R, tests/testthat/test-describe.R</files>
  <behavior>
    describe_draws(draws_obj) extracts metadata from an rbmi draws object:

    **Core fields (all methods):**
    - method: Human-readable method name ("Bayesian (MCMC via Stan)", "Approximate Bayesian", "Conditional Mean (jackknife)", "Conditional Mean (bootstrap)")
    - method_class: Raw class name ("bayes", "approxbayes", "condmean")
    - n_samples: Number of samples (for condmean, displayed as "1 + N")
    - n_failures: Number of failed samples
    - formula: Deparsed model formula string
    - covariance: Covariance structure (e.g., "us")
    - same_cov: Whether same covariance used across groups

    **Condmean-specific:**
    - condmean_type: "jackknife" or "bootstrap"
    - n_primary: 1 (always)
    - n_resampled: length(samples) - 1

    **Bayesian-specific (method_bayes only):**
    - bayes_control: list with warmup, thin, chains, seed
    - mcmc (only when rstan installed AND draws_obj$fit is a stanfit):
      - rhat: Named numeric vector of Rhat per parameter
      - ess: Named numeric vector of ESS per parameter
      - max_rhat: Scalar max Rhat
      - min_ess: Scalar min ESS
      - n_params: Number of Stan parameters
      - converged: logical, TRUE if all Rhat < 1.1 (matching rbmi convention)

    **Return:** S3 class c("describe_draws", "list")

    **print.describe_draws(x, ...):**
    - Uses cli::cli_h1("Draws Summary") header
    - Shows method, formula, samples (with "1 + N" format for condmean), failures, covariance
    - cli::cli_rule() separator
    - If mcmc present: cli::cli_h2("MCMC Convergence"), success/warning alert, max_rhat, min_ess
    - Returns invisible(x)

    **Input validation:**
    - If draws_obj does not inherit "draws", call cli::cli_abort() with class c("rbmiUtils_error_type", "rbmiUtils_error")

    **Edge cases:**
    - approxbayes: Has method_class "approxbayes", same structure as bayes but $fit is NULL (no MCMC diagnostics)
    - condmean with 0 resampled: n_samples = 1, n_resampled = 0
    - rstan not installed: Skip mcmc extraction, optionally emit cli::cli_inform about installing rstan
    - All Rhat NA: converged = NA (use all(..., na.rm = TRUE) carefully -- if no non-NA values, result is TRUE which is misleading; handle explicitly)

    **Test cases (RED phase):**
    1. Input validation: non-draws object -> error with rbmiUtils_error class
    2. Condmean jackknife: returns correct method, formula, sample count (1 + N format), type
    3. Condmean bootstrap: returns correct condmean_type = "bootstrap"
    4. S3 class: result is c("describe_draws", "list")
    5. Bayesian without rstan: mcmc is NULL (mock by setting fit to NULL)
    6. Bayesian with stanfit: mcmc contains rhat, ess, converged (skip_if_not_installed("rstan"))
    7. Print method returns invisible(x) and produces output
    8. approxbayes: No mcmc field (fit is NULL)

    **Mock object construction:**
    Create local helper `make_mock_draws(method_class, ...)` that builds a minimal draws-like list with correct class hierarchy:
    - condmean: class = c("condmean", "draws", "list"), method has class c("method", "condmean"), samples = list of N+1 items, n_failures = 0, formula, fit = NULL
    - bayes: class = c("random", "draws", "list"), method has class c("method", "bayes"), samples, n_failures, formula, fit = stanfit_or_NULL
    - approxbayes: class = c("random", "draws", "list"), method has class c("method", "approxbayes"), samples, n_failures, formula, fit = NULL

    For MCMC test: Use skip_if_not_installed("rstan") and either create a minimal stanfit mock or use a real tiny Stan model.
  </behavior>
