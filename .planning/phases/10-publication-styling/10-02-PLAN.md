Add roxygen @param documentation:
- font_family: "Optional character string specifying the font family for all text in the plot. When NULL (default), uses ggplot2's default font (typically sans-serif). Applied to all geom_text layers and the forest panel theme."
- panel_widths: "Optional numeric vector controlling the relative widths of the plot panels. When show_pvalues = TRUE, must be length 3 (table, forest, p-value panels). When show_pvalues = FALSE, must be length 2 (table, forest panels). When NULL (default), uses c(3, 4, 1.5) for 3-panel and c(3, 5) for 2-panel layouts."

**C. Add panel_widths validation.** After the data preparation section (after `plot_data$pval_label` assignment, before building left panel), add:
```r
# --- Panel width validation ---
if (is.null(panel_widths)) {
  panel_widths <- if (show_pvalues) c(3, 4, 1.5) else c(3, 5)
}
expected_n <- if (show_pvalues) 3L else 2L
if (!is.numeric(panel_widths) || length(panel_widths) != expected_n) {
  cli::cli_abort(
    c("{.arg panel_widths} must be a numeric vector of length {expected_n}.",
      "i" = "Got length {length(panel_widths)}.",
      "i" = if (show_pvalues) {
        "Three widths needed: table panel, forest panel, p-value panel."
      } else {
        "Two widths needed: table panel, forest panel."
      }),
    class = c("rbmiUtils_error_validation", "rbmiUtils_error")
  )
}
```

**D. Add `family = geom_family` to EVERY geom_text() call.** There are 6 geom_text calls in the function (2 in TRT left panel, 2 in LSM left panel, 1 in TRT right panel, 1 in LSM right panel). Add `family = geom_family` as an argument to each one. For example, the TRT left panel visit label geom_text becomes:
```r
ggplot2::geom_text(
  ggplot2::aes(x = 0, label = .data$visit_label),
  hjust = 0, size = text_size, fontface = "bold",
  family = geom_family
)
```

**E. Fix left-panel alignment (STYLE-05).** Change ALL `hjust = 1` to `hjust = 0` in the left panel geom_text calls (both TRT and LSM modes). This switches from right-aligned (ragged left edges) to left-aligned (consistent left edges). There are 4 geom_text calls in left panels (2 for TRT, 2 for LSM). All should use `hjust = 0`.

Also reverse the scale_x_continuous expand multipliers in BOTH TRT and LSM left panels. Change from:
```r
ggplot2::scale_x_continuous(expand = ggplot2::expansion(mult = c(0.3, 0.05)))
```
to:
```r
ggplot2::scale_x_continuous(expand = ggplot2::expansion(mult = c(0.05, 0.3)))
```
This adds space on the right side (where left-aligned text extends) instead of the left.

**F. Update theme_forest() to accept base_family.** Change the signature from `theme_forest <- function(base_size = 11)` to `theme_forest <- function(base_size = 11, base_family = "")`. Pass `base_family` to `ggplot2::theme_minimal(base_size = base_size, base_family = base_family)`.

**G. Update theme_forest() calls.** Both calls to `theme_forest()` in the function body (one in TRT mode, one in LSM mode) should pass the family: `theme_forest(base_family = geom_family)`.

**H. Update the patchwork::plot_layout calls** to use the `panel_widths` variable instead of hardcoded values. Replace:

with:
```r

```
Same for the 2-panel version. Since panel_widths is already resolved (either user-provided or default), both branches just use `panel_widths`.

After editing R/plot_forest.R, run `Rscript -e "devtools::document()"` to regenerate the .Rd file.

IMPORTANT: Do NOT validate font availability. Invalid fonts silently fall back to defaults -- standard behavior.

IMPORTANT: Do NOT add a font_size parameter to plot_forest(). The existing `text_size` parameter already controls geom_text size. Adding separate font_size would be confusing (per research anti-pattern).
