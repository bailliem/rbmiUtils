     ```r

     - If `grepl("^[*:]|[*:]$|[*:]{2}", trimws(term))`: `cli::cli_abort("Malformed interaction term: {.val {term}}.", ...)` -- fail fast.

          class = c("rbmiUtils_error_validation", "rbmiUtils_error")
        )
      }
      ```
