  2. Create R/efficacy_table.R with the following components:

  **is_gt_available() helper** (internal, not exported, `@noRd`):
  - Mirrors the is_cards_available() pattern from R/ard_conversion.R exactly
  - Returns `requireNamespace("gt", quietly = TRUE)`

  **efficacy_table() function** (exported, with full roxygen docs):

  Function signature:
  ```r
  efficacy_table <- function(
    pool_obj,
    title = NULL,
    subtitle = NULL,
    digits = 2,
    ci_level = NULL,
    arm_labels = NULL,
    pval_digits = 3,
    pval_threshold = 0.001,
    ...
  )
  ```

  Implementation flow (internal two-step design):

  **Step A: Validation & metadata extraction**
  - Check is_gt_available(), abort with cli::cli_abort() if missing (class: rbmiUtils_error_dependency)
  - Validate pool_obj inherits "pool" (class: rbmiUtils_error_validation)
  - Extract ci_level: use argument, fall back to pool_obj$conf.level, fall back to 0.95
  - Extract method: pool_obj$method %||% "unknown"
  - Extract n_imputations: pool_obj$N

  **Step B: Data preparation**
  - Call tidy_pool_obj(pool_obj) to get tidy data frame
  - Clean visit labels: gsub("_", " ", visit), then tools::toTitleCase()
  - Preserve visit ordering: convert visit_label to factor with levels in the order they appear in tidy_df (which preserves pool object ordering)
  - Apply arm_labels: if provided (named vector with "ref" and "alt" elements), use those; otherwise default to "Reference" / "Treatment"
  - Create row_label column:
    - lsm + ref -> "LS Mean ({ref_label})"
    - lsm + alt -> "LS Mean ({alt_label})"
    - trt -> "Treatment Difference"
  - Create row_order column: ref=1L, alt=2L, trt=3L, other=4L
  - Create ci_text column: sprintf("(%s, %s)", formatC(lci, format="f", digits=digits), formatC(uci, format="f", digits=digits))
  - Create pval_text column: ifelse(is.na(pval), "\u2014", format_pvalue(pval, digits = pval_digits, threshold = pval_threshold))
  - Arrange by visit_label (factor order), then row_order
  - Select: visit_label, row_label, est, se, ci_text, pval_text

  **Step C: gt table construction**
  - gt::gt(rowname_col = "row_label", groupname_col = "visit_label")
  - gt::fmt_number(columns = c(est, se), decimals = digits)
  - gt::cols_label(): est="Estimate", se="Std. Error", ci_text="{ci_level*100}% CI", pval_text="P-value"
  - gt::cols_align(align = "center", columns = dplyr::everything())
  - gt::opt_align_table_header(align = "left")
  - If title or subtitle provided: gt::tab_header(title = title, subtitle = subtitle)
  - Footnotes via gt::tab_source_note() -- add ALL THREE (TBL-04 requirement):
    1. "Pooling method: {method}"
    2. "Number of imputations: {n_imputations}"
    3. "Confidence level: {ci_level * 100}%"
  - Return the gt object

  **Roxygen documentation:**
  - @title "Create Regulatory-Style Efficacy Summary Table"
  - @description explaining the Table 14.2.x format, visit row groups, etc.
  - @param for all parameters with clear descriptions
  - @return "A gt table object of class `gt_tbl`"
  - @details section explaining: single-parameter assumption, arm_labels usage, customization via gt piping
  - @seealso links to tidy_pool_obj(), format_pvalue(), rbmi::pool()
  - @examples section wrapped in \donttest{} with requireNamespace("gt") guard, showing basic usage with mock pool
  - @export
