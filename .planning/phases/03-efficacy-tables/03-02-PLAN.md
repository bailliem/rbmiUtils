  <files>R/efficacy_table.R</files>
  <action>
  Enhance efficacy_table() in R/efficacy_table.R with the following:

  **1. Visit ordering preservation (Pitfall 1 from research):**
  After creating visit_label, ensure it is a factor whose levels follow the unique visit order from tidy_df (which inherits order from the pool object's parameter list). This prevents gt from alphabetically sorting visits. Use:
  ```r
  visit_order <- unique(tidy_df$visit_label)  # preserves first-appearance order
  tidy_df$visit_label <- factor(tidy_df$visit_label, levels = visit_order)
  ```
  Then after arrange(), call gt::row_group_order(groups = visit_order) on the gt object to enforce group display order.

  **2. Multi-parameter warning (Pitfall 5 from research):**
  After calling tidy_pool_obj(), check if there are unexpected parameter types beyond the standard "trt" and "lsm". If tidy_df contains parameter_type values other than "trt" and "lsm", emit a cli::cli_warn():
  ```r
  unexpected_types <- setdiff(unique(tidy_df$parameter_type), c("trt", "lsm"))
  if (length(unexpected_types) > 0) {
    cli::cli_warn(
      "Unexpected parameter types detected: {.val {unexpected_types}}. efficacy_table() is designed for standard ANCOVA pool objects.",
      class = "rbmiUtils_warning"
    )
  }
  ```
  Also check: if there are multiple distinct visit values AND some rows have NA visits, warn about potential multi-parameter structure.

  **3. Single-visit pool handling:**
  Verify the function works when the pool object has only one visit (e.g., only "Week24"). No code change needed if the implementation is general, but verify no edge case failures.

  **4. NA visit handling:**
  If any rows in tidy_df have NA visits, filter them out with a warning:
  ```r
  na_visit_rows <- is.na(tidy_df$visit)
  if (any(na_visit_rows)) {
    cli::cli_warn(
      "{sum(na_visit_rows)} row{?s} with missing visit information excluded from table.",
      class = "rbmiUtils_warning"
    )
    tidy_df <- tidy_df[!na_visit_rows, ]
  }
  ```

  **5. Empty result guard:**
  After filtering, if nrow(tidy_df) == 0, abort with a clear message.

  Run devtools::document() to update NAMESPACE/docs.
