plot_forest <- function(
    pool_obj,

**4. Function body implementation order:**

a) **Dependency checks:** Check ggplot2 and patchwork with `cli::cli_abort()` using error class `c("rbmiUtils_error_dependency", "rbmiUtils_error")`. Same pattern as efficacy_table.R.

b) **Input validation:** Check `pool_obj` is class "pool" with `inherits()`. Use `match.arg(display)`.

c) **Metadata extraction:** Extract `ci_level` from `pool_obj$conf.level %||% 0.95` if NULL. Set `ref_value` default: 0 for `display == "trt"`, NULL for `display == "lsm"`.

d) **Data preparation:** Call `tidy_pool_obj(pool_obj)` to get tidy data frame. Filter by `parameter_type`: "trt" for treatment differences, "lsm" for LS means. Remove rows with `is.na(visit)`. Clean visit labels using the exact pattern from efficacy_table.R:
```r
visit_clean <- gsub("_", " ", plot_data$visit)
visit_clean <- gsub("([a-zA-Z])(\\d)", "\\1 \\2", visit_clean)
plot_data$visit_label <- tools::toTitleCase(visit_clean)
```
Convert to factor preserving first-appearance order: `factor(visit_label, levels = unique(visit_label))`.

e) **Significance detection:** If `ref_value` is not NULL, compute `plot_data$significant <- (plot_data$lci > ref_value) | (plot_data$uci < ref_value)`. Otherwise set all FALSE.

f) **Format text columns:** Use `format_estimate()` for the estimate (CI) text label. Use `format_pvalue()` for p-value labels. Handle NA p-values with an em-dash "\u2014".

g) **LSM arm labels:** For `display == "lsm"`, create arm label column. Default arm labels: "Reference" and "Treatment". If `arm_labels` is provided (named vector with "ref" and "alt"), use those. Map from `lsm_type` column in tidy data (values are "ref" or "alt" for ANCOVA, or actual arm names for gcomp).

h) **Build left panel (table):** A ggplot with `geom_text()` showing visit labels and estimate (CI) text. Use `theme_void()`. Set `scale_y_discrete(limits = rev)` for top-to-bottom visit ordering. Add column header via a labs subtitle or annotation. For `display == "lsm"`, show arm-level rows within each visit.

i) **Build middle panel (forest plot):**
- For `display == "trt"`: Use `ggplot2::geom_linerange(aes(xmin = lci, xmax = uci, y = visit_label), linewidth = 0.6)` for CI whiskers (NO caps). Use `ggplot2::geom_point(aes(x = est, y = visit_label, shape = significant), size = point_size)` with `scale_shape_manual(values = c("TRUE" = 16, "FALSE" = 1), guide = "none")` for significance highlighting (filled vs open circles).
- For `display == "lsm"`: Use `position_dodge(width = 0.4)` on both geoms. Color by arm using Okabe-Ito palette: blue (#0072B2) for reference arm, vermillion (#D55E00) for treatment arm. Extract via `grDevices::palette.colors(palette = "Okabe-Ito")`.
- Add solid reference line: `ggplot2::geom_vline(xintercept = ref_value, linewidth = 0.5)` if `ref_value` is not NULL.
- Apply clinical theme: white background, minimal gridlines, no y-axis text/title (labels are in left panel). Use `theme_minimal()` as base, then customize.
- X-axis label: "Treatment Difference" for trt mode, "LS Mean Estimate" for lsm mode.

j) **Build right panel (p-values):** A ggplot with `geom_text()` showing formatted p-values. `theme_void()`. Same `scale_y_discrete(limits = rev)` with identical factor levels.

k) **Combine with patchwork:** `p_left + p_mid + p_right + patchwork::plot_layout(widths = c(3, 4, 1.5))`. If title is provided, add `patchwork::plot_annotation(title = title)`.

l) **Return:** Return the combined patchwork object (inherits from ggplot).

**5. Roxygen documentation:**
Full roxygen docs following the exact style in `efficacy_table.R`: `@param`, `@return`, `@details`, `@seealso` (link to tidy_pool_obj, efficacy_table, format_pvalue), `@examples` with `\donttest{}` wrapping, `@export`.

**Important anti-patterns to avoid (from RESEARCH.md):**
- Do NOT use `coord_flip()` -- map visits to y-axis directly
- Do NOT use `geom_errorbar()` or `geom_errorbarh()` -- they add caps; use `geom_linerange()`
- Do NOT use `geom_pointrange()` -- complicates significance highlighting
- Do NOT save files -- return the ggplot object only
- Do NOT move ggplot2 to Imports -- keep in Suggests
- Do NOT use `is.ggplot()` -- deprecated in ggplot2 3.5.2+
