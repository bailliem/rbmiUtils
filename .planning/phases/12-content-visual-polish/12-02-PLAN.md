  <files>R/plot_forest.R</files>
  <action>
Modify `plot_forest()` and `theme_forest()` in `R/plot_forest.R` with these specific changes. All changes are per user decisions in CONTEXT.md.

**Default parameter changes:**
- `text_size = 3` -> `text_size = 3.5` (bumped up for regulatory readability)
- `point_size = 3` -> `point_size = 3.5` (bumped up)
- In `theme_forest()`: `base_size = 11` -> `base_size = 12` (bumped up)

**Typography (bold visit labels and headers):**
- In the trt-mode left panel, visit label `geom_text` already has `fontface = "bold"` -- keep it.
- In the LSM-mode left panel, the row_label `geom_text` does NOT have bold -- leave as-is since row_label includes arm name.
- For column headers (the `labs(subtitle = ...)` on each panel): apply bold styling via theme. Add to each panel after `labs()`:
  `ggplot2::theme(plot.subtitle = ggplot2::element_text(face = "bold", size = ggplot2::rel(1.1)))`
- For the p-value panel subtitle similarly.

**Bold/larger plot title:**
- In the patchwork `plot_annotation(title = title)` call, add theme:
  After `patchwork::plot_annotation(title = title)`, chain: `& ggplot2::theme(plot.title = ggplot2::element_text(face = "bold", size = ggplot2::rel(1.3)))`
  BUT only apply the title theme to the annotation, not to all panels. Use:
  `patchwork::plot_annotation(title = title, theme = ggplot2::theme(plot.title = ggplot2::element_text(face = "bold", size = ggplot2::rel(1.3))))`

**Dashed reference line:**
- Change `geom_vline(xintercept = ref_value, linewidth = 0.5)` to:
  `geom_vline(xintercept = ref_value, linewidth = 0.5, linetype = "dashed")`
- Apply in BOTH trt and lsm mode reference line blocks.

**Forest panel border:**
- In `theme_forest()`, change `panel.background`:
  From: `ggplot2::element_rect(fill = "white", colour = NA)`
  To: `ggplot2::element_rect(fill = "white", colour = "grey70", linewidth = 0.3)`

**Horizontal lines between visit rows:**
- In `theme_forest()`, change `panel.grid.major.y`:
  From: `ggplot2::element_blank()`
  To: `ggplot2::element_line(colour = "grey90", linewidth = 0.3)`

**Tighter row spacing (compact layout):**
- In the forest panel for trt mode, after `scale_y_discrete(limits = rev)`, add:
  `ggplot2::theme(axis.text.y = ggplot2::element_blank(), panel.spacing = ggplot2::unit(0.1, "lines"))`
  Actually, the compact spacing is controlled by the y-axis expansion. Add to the forest panel:
  `ggplot2::scale_y_discrete(limits = rev, expand = ggplot2::expansion(add = 0.3))`
  (replacing the existing `scale_y_discrete(limits = rev)`)
  Also apply in LSM mode forest panel and left panels for consistency.
  Also apply in p-value panels.

**Descriptive x-axis title:**
- In trt mode, change `labs(x = "Treatment Difference")` to:
  `labs(x = "Treatment Difference (95% CI)")` -- but dynamically use ci_label:
  `labs(x = paste0("Treatment Difference (", ci_label, ")"))`
  Note: `ci_label` is already computed as `paste0(ci_level * 100, "% CI")` earlier in the function.
- In lsm mode, change `labs(x = "LS Mean Estimate")` to:
  `labs(x = paste0("LS Mean Estimate (", ci_label, ")"))`

**Suggested dimensions documentation:**
- Add to the @details roxygen section a paragraph:
  "**Suggested dimensions for regulatory documents:** For A4 or US Letter page sizes, `width = 10, height = 3 + 0.4 * n_visits` (in inches) provides good results when saving with `ggplot2::ggsave()`. For example, a 5-visit plot works well at 10 x 5 inches."

**CI whisker line weight** (Claude's discretion):
- Change `geom_linerange(linewidth = 0.6)` to `geom_linerange(linewidth = 0.7)` for slightly better print visibility. Apply in both trt and lsm mode.

After all changes, run `devtools::document()` to regenerate Rd files if roxygen was modified.
