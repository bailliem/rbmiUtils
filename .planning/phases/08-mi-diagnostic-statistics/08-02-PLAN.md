       - For each parameter in names(analysis_obj$results[[1]]):

         b. Get v_com = unique(dfs)[1] (complete-data df, constant across imputations)

         d. Build diagnostic ARD rows for this parameter

       - Stat names: c("fmi", "lambda", "riv", "df.adjusted", "df.complete", "var.within", "var.between", "var.total", "re", "m.imputations")
       - Stat labels: c("Fraction of Missing Information", "Lambda", "Relative Increase in Variance", "Barnard-Rubin Adjusted df", "Complete-Data df", "Within-Imputation Variance", "Between-Imputation Variance", "Total Variance", "Relative Efficiency", "Number of Imputations")
       - Stat values: list(diag$fmi, diag$lambda, diag$riv, diag$df_adj, diag$dfcom, diag$var_w, diag$var_b, diag$var_t, diag$re, M)
       - Use SAME grouping columns as the base ARD rows (group1="visit", group1_level=param_row$visit, group2="parameter_type", group2_level=param_row$parameter_type, group3="lsm_type", group3_level=lsm_val, variable=param_row$parameter)
       - Use I(as.list(...)) for all list columns (stat, group levels, warning, error, fmt_fun, variable_level)
       - context = "rbmi_pool" (same as base rows)
       - fmt_fun = I(as.list(rep(1L, n_diag)))

       - Update @return to mention diagnostic stat rows
