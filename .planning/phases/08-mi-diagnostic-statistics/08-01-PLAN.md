<feature>
  <name>Rubin's Rules Diagnostic Computation</name>
  <files>R/ard_conversion.R, tests/testthat/test-ard_conversion.R</files>
  <behavior>
    compute_rubin_diagnostics(ests, ses, v_com, M) returns a named list with:
    - var_w: within-imputation variance = mean(ses^2)
    - var_b: between-imputation variance = var(ests)
    - var_t: total variance = var_w + var_b + var_b/M
    - lambda: (1 + 1/M) * var_b / var_t
    - riv: (1 + 1/M) * var_b / var_w
    - df_adj: Barnard-Rubin adjusted degrees of freedom
    - dfcom: complete-data df (pass-through of v_com)
    - fmi: adjusted FMI = (riv + 2/(df_adj + 3)) / (1 + riv)
    - re: relative efficiency = 1 / (1 + fmi/M)

    Test cases:
    1. Known values: M=5, ests=c(1.0, 1.2, 0.8, 1.1, 0.9), ses=c(0.5, 0.6, 0.4, 0.55, 0.45), v_com=100
       -> Verify var_w = mean(ses^2), var_b = var(ests), and all derived quantities match hand-calculated values
    2. Edge case: lambda near 0 (all ests identical, e.g., ests=rep(1.0, 5))
       -> var_b = 0, lambda = 0, riv = 0, fmi near 0, re near 1
    3. Edge case: v_com = Inf (large-sample, no complete-data df constraint)
       -> df_adj uses only v_old = (M-1)/lambda^2 when lambda > 0
    4. Edge case: all SEs are NA
       -> All diagnostic values should be NA
    5. Verify fmi != lambda (adjusted FMI is distinct from lambda per mice convention)
  </behavior>
  <implementation>
    Add compute_rubin_diagnostics() as a non-exported (#' @noRd) internal function at the bottom of R/ard_conversion.R (after the existing is_cards_available helper). The function takes 4 arguments: ests (numeric vector of per-imputation point estimates), ses (numeric vector of per-imputation standard errors), v_com (numeric scalar for complete-data degrees of freedom), M (integer, number of imputations).

    Follow the exact formulas from the RESEARCH.md Pattern 3 section, which were verified against rbmi:::rubin_rules and rbmi:::rubin_df source code.

    Edge case handling:
    - If all SEs are NA: return list with all values NA
    - If var_b == 0 (lambda == 0): df_adj = v_obs (skip v_old which would be Inf)
    - If v_com is Inf and var_b == 0: df_adj = Inf
    - If v_com is Inf and lambda > 0: df_adj = v_old = (M-1)/lambda^2
    - If v_com is NA: df_adj = NA, fmi = NA, re = NA

    Mirror rbmi:::rubin_df() edge case logic exactly as documented in RESEARCH.md Pattern 3.
  </implementation>
</feature>
