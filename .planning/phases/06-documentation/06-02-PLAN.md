**Narrative structure** (tutorial tone, walking the reader through step by step):

**1. Introduction** (~3 paragraphs)
- What this vignette covers: the complete pipeline from raw clinical trial data to publication-ready outputs
- Brief context: [rbmi](https://cran.r-project.org/package=rbmi) implements reference-based multiple imputation; rbmiUtils adds reporting and data preparation utilities on top
- What the reader will produce: an efficacy summary table and a forest plot
- Link to the [analyse2 vignette](analyse2.html) for a more focused analysis reference, and the [data preparation vignette](data-preparation.html) for detailed data prep guidance

**2. Setup and Data** (~2 paragraphs + code)
- `library()` calls: rbmi, rbmiUtils, dplyr (and conditionally ggplot2, patchwork, gt for output rendering)
- Load ADEFF dataset: `data("ADEFF", package = "rbmiUtils")`
- Brief description of ADEFF: a simulated ADaM efficacy dataset with continuous change-from-baseline outcomes, missingness, and two treatment arms
- Show `str(ADEFF)` or `head(ADEFF)` so the reader sees the data structure
- Factor preparation: TRT, USUBJID, AVISIT as factors

**3. Data Preparation** (~3-4 paragraphs + code, brief per discretion)
- `validate_data()`: Run it and show the success message. Explain this catches common issues before the slower imputation step. Link to [data preparation vignette](data-preparation.html) for full details.
- `summarise_missingness()`: Show the summary output. Brief interpretation of missing data patterns.
- Do NOT include prepare_data_ice() in this section -- the ADEFF simple pipeline does not use ICE flags. Mention it exists and link to the data prep vignette.

**4. rbmi Analysis Pipeline** (~5-6 paragraphs + code)
This is the core section showing the rbmi pipeline with explanation:
- `set_vars()`: Define analysis variables (subjid, visit, group, outcome, covariates). Explain each field briefly.
- `method_bayes()`: Specify imputation method. Use n_samples=100, warmup=200, thin=2 for the vignette (fast enough for building). Explain this controls MCMC sampling. Link to [rbmi documentation](https://cran.r-project.org/web/packages/rbmi/vignettes/quickstart.html) for statistical details.
- `draws()`: Fit the imputation model. Note this is the computationally intensive step.
- `impute()`: Generate imputed datasets under the reference-based assumption.
- `analyse()` via `analyse_mi_data()`: Apply ANCOVA to each imputed dataset. Explain that rbmiUtils wraps `rbmi::analyse()` to provide the `ancova` convenience function. Show the ancova call.
- `pool()`: Pool results using Rubin's rules. Link to [rbmi::pool()](https://cran.r-project.org/package=rbmi) documentation.
- Show the resulting pool_obj print output.

**5. Tidying Results** (~2 paragraphs + code)
- `tidy_pool_obj()`: Convert pool object to a tidy tibble. Show the output.
- Explain the columns: parameter, description, visit, parameter_type, lsm_type, est, se, lci, uci, pval
- Mention `format_results_table()` for adding formatted columns.

**6. Efficacy Table** (~3 paragraphs + code)
- `efficacy_table()`: Create a regulatory-style gt table. Show with default arguments first.
- Show a customized version with `title`, `subtitle`, `arm_labels`.
- Note this produces a gt object that can be further customized with gt functions.
- Wrap in `if (requireNamespace("gt", quietly = TRUE))` guard since gt is Suggests.

**7. Forest Plot** (~3 paragraphs + code)
- `plot_forest()`: Create a three-panel forest plot. Show the default "trt" mode.
- Show the "lsm" display mode with arm_labels.
- Explain customization via `& theme()`.
- Wrap in `if (requireNamespace("ggplot2", quietly = TRUE) && requireNamespace("patchwork", quietly = TRUE))` guard.

**8. Appendix: Binary/Responder Analysis** (~4-5 paragraphs + code, concise)
- Brief section showing how the pipeline differs for binary endpoints
- Use ADMI dataset (pre-computed, avoids another draws() call in the vignette)
- Show `gcomp_responder()` with [beeca](https://openpharma.github.io/beeca/) for the g-computation step
- Show that the same `efficacy_table()` and `plot_forest()` work on the pooled binary results
- Keep this shorter than the main continuous walkthrough -- just highlight the differences
