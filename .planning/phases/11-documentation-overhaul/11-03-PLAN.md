IMPORTANT: This setup uses `analyse_mi_data()` which works DIRECTLY with ADMI (pre-imputed data with IMPID column). It does NOT need draws(), impute(), or data_ice. The function signature is `analyse_mi_data(data, vars, method, fun, delta, ...)` -- read R/analyse_mi_data.R to confirm. The setup chunk is needed for the pool_to_ard section (Section 5).

Use dplyr for any data manipulation (not base R filtering). Example:
```r
library(rbmiUtils)
library(rbmi)
library(dplyr)

data("ADMI", package = "rbmiUtils")
ADMI <- ADMI |>
  mutate(
    TRT = factor(TRT, levels = c("Placebo", "Drug A")),
    USUBJID = factor(USUBJID),
    AVISIT = factor(AVISIT)
  )

vars <- set_vars(
  subjid = "USUBJID", visit = "AVISIT", group = "TRT",
  outcome = "CHG", covariates = c("BASE", "STRATA", "REGION")
)
method <- method_bayes(
  n_samples = 100,
  control = control_bayes(warmup = 200, thin = 5)
)

ana_obj <- analyse_mi_data(ADMI, vars, method, fun = ancova)
pool_obj <- pool(ana_obj)
```
